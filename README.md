# Rossi Satria — Portfolio Website

🌐 Website portofolio profesional yang dibangun dengan HTML, CSS, dan JavaScript vanilla.

## 🚀 Features

- **Responsive Design** — Tampil rapi di mobile, tablet, dan desktop
- **Dark Premium Theme** — Desain modern dengan glassmorphism dan micro-animations
- **Project Filter** — Filter proyek berdasarkan kategori (Web Dev, Networking, Manajerial)
- **Smooth Scrolling** — Navigasi mulus antar section
- **Typing Effect** — Animasi mengetik pada hero section
- **Scroll Reveal** — Animasi elemen saat scroll ke viewport
- **Download CV** — Tombol akses langsung untuk unduh CV

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom properties, Grid, Flexbox, Animations
- **JavaScript** — Vanilla ES6+, IntersectionObserver API
- **Fonts** — Inter, Space Grotesk, JetBrains Mono (Google Fonts)

## 📁 Structure

```
├── index.html          # Single page application
├── css/
│   └── style.css       # Complete design system
├── js/
│   └── main.js         # All interactivity
├── assets/
│   ├── images/         # Profile & project images
│   └── docs/           # CV PDF
└── README.md
```

## 📦 Deployment

1. Push ke repository `[username].github.io`
2. Aktifkan GitHub Pages di Settings → Pages
3. Set source branch ke `main`
